# @memly/study-engine

Будущая чистая логика: выбор карточек, генерация вопросов, нормализация и проверка ответов, политики режима обучения и адаптер FSRS.

Время, случайность и настройки передаются явно. Здесь нет HTTP, React, доступа к БД или вызовов AI. Сервер использует движок для принятия решений; клиент может использовать безопасные вспомогательные функции.
