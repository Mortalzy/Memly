# Инфраструктура Memly

На первом этапе здесь появится Docker Compose для локального PostgreSQL. Redis, объектное хранилище, контейнеры приложений и Caddy добавляются по мере реализации использующих их функций.

Целевое развёртывание: React-сборка и API за одним HTTPS-доменом, PostgreSQL в закрытой сети, отдельный worker при необходимости. Перед публичным запуском проверяются миграции, резервное копирование и восстановление, мониторинг и конфигурация секретов.

Инфраструктура пока не создана и не развёрнута.
