# Memly

Memly — приложение для обучения с карточками, практикой, тестами и играми. Ориентир по возможностям — Quizlet; интерфейс, код, контент и название создаются для Memly.

## Текущий статус

Подготовлены архитектура и план разработки; в `apps/web` создан интерактивный фронтенд-прототип выбранного бело-розового дизайна. Есть главная, библиотека, папки, наборы, демонстрации учебных режимов, редактор, прогресс и настройки. API, авторизация, база и настоящие учебные алгоритмы пока не реализованы. Другие приложения и общие пакеты остаются заготовками.

## Посмотреть и запустить прототип

Прототип: https://memly-design-preview.warmaksimus7.chatgpt.site (приватный просмотр владельцем).

Нужны Node.js 24 и npm 11 (npm поставляется вместе с Node.js). В корне репозитория:

```bash
npm ci
npm run dev
```

Откройте адрес Vite в терминале. `npm run build` создаёт статический `dist/`; `npm run preview` позволяет посмотреть сборку.
Проверки: `npm run typecheck`, `npm run format:check`, `npm test`.
Демонстрационные изменения сбрасываются при обновлении страницы; итог теста и статистика — примеры оформления.
[Все экраны, границы и структура прототипа](docs/prototype.md).

## Зафиксированный стек

- TypeScript на клиенте, сервере и в общих пакетах; Node.js 24 LTS.
- React 19 + Vite + React Router + TanStack Query.
- Tailwind CSS + Radix UI; React Hook Form + Zod.
- Express 5, REST API, Better Auth с серверными сессиями.
- PostgreSQL 18 + Drizzle ORM + Drizzle Kit; драйвер `pg`.
- FSRS через `ts-fsrs` для интервальных повторений.
- npm workspaces, ESLint, Prettier, GitHub Actions.
- Vitest, React Testing Library, MSW, Supertest, Testcontainers, Playwright.
- Docker Compose для разработки, Docker + Caddy для целевого развёртывания.

По мере появления соответствующих функций добавляются Redis + BullMQ, Socket.IO, S3-совместимое хранилище, Tiptap + KaTeX и PWA с IndexedDB. Эти сервисы не нужны для текущей документационной инициализации.

Зависимости фронтенд-прототипа и npm уже зафиксированы в манифестах и `package-lock.json`. Остальной стек подключается по плану при реализации приложения.

## Структура

| Каталог | Назначение |
| --- | --- |
| `apps/web` | React-клиент |
| `apps/api` | Express API и бизнес-модули |
| `apps/worker` | Фоновая обработка файлов, генерации и уведомлений |
| `packages/contracts` | Публичные схемы запросов, ответов и событий |
| `packages/study-engine` | Правила обучения и повторений без зависимости от UI и БД |
| `packages/database` | Серверная схема данных, миграции и подключение |
| `packages/ui` | Общие визуальные компоненты и токены |
| `infra` | Будущая инфраструктура разработки и эксплуатации |
| `docs` | План, исследования и архитектурные решения |

## Начальные предположения

Сначала создаётся адаптивное веб-приложение с русским интерфейсом и возможностью последующей локализации. Полный набор возможностей реализуется последовательными релизами. Нативные мобильные приложения, коммерческая модель, платёжный и AI-провайдеры требуют отдельного продуктового решения; варианты и последствия указаны в плане.

## Форматирование

В JS/TS/TSX, JSON и YAML используется отступ в два пробела, UTF-8 и LF. Настройки закреплены в `.editorconfig` и `.prettierrc.json`. Подробные правила находятся в [code-style.md](docs/code-style.md).
