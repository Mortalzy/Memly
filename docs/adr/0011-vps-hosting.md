# ADR 0011: запуск на одном VPS

Дата: 2026-10-14. Статус: принято для подготовки; публичный VPS ещё не проверен.

## Решение

Использовать системный Node.js 24, PostgreSQL 18 на localhost, Nginx как единственный
HTTPS reverse proxy и systemd с отдельным пользователем memly. React обслуживается
существующим Express-сервером из dist. Docker и PM2 для этой схемы не требуются.

Команда build:production валидирует настройки и исключает деморежим. hosting:check
проверяет файлы, применённые миграции, соединение с БД и SMTP без отправки писем.
Параметры почтового транспорта общие с auth; соединения имеют конечные таймауты.
Корневой auth URL должен принадлежать TRUSTED_ORIGINS; DATABASE_URL проверяется как URL PostgreSQL.
Все соединения БД используют UTC независимо от timezone сервера и URL options;
это предотвращает смещение сохранённых дат при сериализации Prisma Pg.
Время установления соединения с БД ограничено 10 секундами.

Служба не может изменять системные файлы и код. Nginx перезаписывает forwarded-заголовки,
Express слушает loopback, TRUST_PROXY=1. HTTP служит только ACME и перенаправлению на HTTPS;
до сертификата используется отдельный bootstrap-конфиг. Запросы auth с токенами не
попадают в Nginx access log. Конфигурация не запускает публичный Vite dev/preview.

## Последствия

Простой установка и обновление на одном сервере, но обновление имеет короткий простой.
PostgreSQL и HTTP-лимитер не распределены. Резервные копии нужно выносить с VPS и
проверять восстановлением. DNS, сертификат и доставку писем проверяют после установки.
Прежний домашний запуск через ngrok сохраняется отдельным вариантом (ADR 0010).
