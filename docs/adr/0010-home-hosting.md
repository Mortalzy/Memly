# ADR 0010: личный запуск через ngrok

Дата: 2026-10-12. Статус: принято для первого запуска с компьютера Windows 11.

## Контекст

Нужен доступ к Memly для двух пользователей с разных устройств, без аренды сервера.
Ранее Express обслуживал только API, а Vite — интерфейс в development.

## Решение

В production Express также обслуживает корневой `dist`, созданный Vite. Каталог
вычисляется относительно модуля сервера, независимо от рабочей директории.
Отсутствие index.html останавливает запуск. API обрабатывается до статических файлов;
неизвестные API и отсутствующие assets сохраняют 404. Hash-навигация не требует SPA fallback.
Сервер по умолчанию слушает loopback, другой HOST задаётся явно.
Туннель ngrok подключается к одному порту. Сохраняются требования HTTPS, SMTP,
Secure-cookie, точного Origin и существующая проверка прав.

## Последствия

Production не требует Vite или отдельного reverse proxy для статики. PostgreSQL
не публикуется. Первый запуск ручной: npm start и npm run tunnel. Компьютер и сеть
должны работать; автозапуск и мониторинг — отдельная задача. Резервные копии pg_dump
пишутся в игнорируемый git каталог; восстановление проверяется в отдельной базе.
TRUST_PROXY остаётся 0 до отдельной проверки доверенной цепочки: лимит общий для туннеля.
SMTP и доступ из сети проверяются на пользовательском компьютере после установки.
