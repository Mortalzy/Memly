# ADR 0008: Готовые уровни сканворда

Дата: 11 октября 2026. Статус: принято. Заменяет источник новых игр из ADR 0007.

## Решение

Сканворд становится отдельным каталогом пяти готовых уровней: «Разминка» (6 слов),
«Мир вокруг» (8), «Природа» (10), «Наука и техника» (12), «Финальный вызов» (15).
У каждого уровня постоянные английские слова/вопросы, координаты и одна сетка до 22×22.
Сетки подготовлены заранее и проверяются движком при создании снимка; во время игры
они не генерируются из пользовательских наборов. Публичные метаданные находятся в
contracts, решения и раскладки — в отдельном entry point study-engine/scanword-levels.
Обычный production-клиент не включает этот каталог ответов. Он загружается клиентом
только в явно включённой демосборке VITE_DEMO_MODE=true.

## Хранение и доступ

Повторно используем StudySession/StudyEvent и существующие правила идемпотентности,
ревизий и сохранения черновика. SQL-миграция делает deck_id nullable и добавляет
level_key с индексом user_id/level_key/status. CHECK требует ровно один источник:
набор либо готовый уровень режима scanword. Старые сессии и связи с наборами сохраняются.
DTO сессии/истории содержит deckId=null и levelId для готового уровня; старые записи
имеют прежний deckId и levelId=null. deckTitle/deckRevision сохраняют название/версию
источника в снимке для совместимости существующего API истории.

Первый уровень доступен сразу. Сервер разрешает запуск/восстановление следующего,
только когда у этого пользователя есть completed-сессии всех предыдущих уровней.
Клиент не передаёт unlocked/completed, ответы, сетку или настройки: только requestId.
Попытка открыть закрытый уровень напрямую получает 403 LEVEL_LOCKED. Чужая сессия — 404.
События используют прежний endpoint и серверную проверку полностью заполненных слов.
Ключи запуска/событий повторяются после потери ответа без создания дополнительных зачётов.

Галочка и процент прохождения каталога выводятся из completed-сессий по уникальным
level_key; повтор или прерывание новой попытки не удаляют прежнюю галочку. Повторное
полное прохождение увеличивает общий дневной прогресс ещё на одно занятие, как в
остальных режимах. Каталог остаётся 5/5. Ошибки и подсказки снижают самостоятельный
результат, но не мешают разблокировке после всех проверенных слов. Готовые уровни
не создают Deck/Card, не пишут CardProgress или ReviewEvent.

Агрегация дневной активности и история учитывают оба источника, сохраняя проверку
владельца и доступности набора для старых занятий. Новый источник не зависит от
наличия наборов в библиотеке. Удаление аккаунта удаляет его сессии каскадно.

## Интерфейс и совместимость

Маршруты: games → games/scanword → games/scanword/:levelId; query session открывает
конкретную попытку из истории. Каталог показывает все пять карточек, галочки, доступный
уровень, замки, продолжение активной попытки и суммарный прогресс. Вход в доступный
уровень автоматически восстанавливает активную попытку или создаёт новую. После
завершения показаны результат, переход к следующему и повтор полного уровня.

Новые сканворды из наборов через /study/sessions получают 400 READY_LEVELS_ONLY.
Ранее сохранённые игры можно продолжать и просматривать в прежнем маршруте, без
нового запуска/повтора из набора. Механика ввода и автосохранения остаётся из ADR 0007.
Демо хранит результаты только в памяти страницы и явно предупреждает об этом.

## Проверки

Движок проверяет постоянство и разрешимость пяти сеток, отсутствие открытых ответов
в активном DTO, конфликты пересечений и границы. UI проверяет замки, завершение,
галочку, открытие следующего, ввод/вставку, сетевые повторы и сохранение при уходе.
API с PostgreSQL проверяет обход блокировки прямым запросом, разделение пользователей,
восстановление, все пять прохождений, повтор/прерывание, дневной прогресс, отсутствие
созданных наборов/карточного прогресса и доступ к старым сессиям. SQL-миграции выполняются
последовательно. Интеграционные наборы очищают auth rate_limits в memly_test перед
запуском, чтобы не наследовать лимиты предыдущего набора; production-защита неизменна.

## Английская редакция и адаптивное поле

Редакция 2 от 11 октября 2026 заменяет русские вопросы и ответы английскими во всех
пяти уровнях. Раскладки составлены заранее и остаются постоянными; генерации при
запуске игры нет. Автовосстановление и карточка «Продолжить» выбирают только активную
сессию текущей редакции. Прямое открытие прежней попытки сохраняет её снимок и показывает
outdated=true с возможностью начать английскую игру. Старые завершения сохраняют
галочки/доступ; новая редакция не сбрасывает достижения. Новая миграция не нужна.

Убираем обрезанные вопросы из клеток: там номер и направление, полные вопросы — в
списке и панели выбранного слова. Выбор в списке выделяет соответствующее слово.
Клиент английской редакции принимает только латинские буквы при вводе и вставке;
старые снимки сохраняют двуязычный ввод. ResizeObserver рассчитывает размер клеток
по ширине и высоте контейнера с учётом границ/зазоров. На компьютере игровая панель
занимает оставшуюся высоту окна без повторного заголовка набора и лишнего подвала.
На телефоне поле вписывается целиком, вопросы переносятся вниз без обрезки, кнопки
проверки/сохранения закреплены у нижнего края.

Проверки включают английский алфавит/разрешимость всех сеток, полные вопросы/выбор
в списке, восстановление редакции 2 и сохранение достижений редакции 1, геометрию
всех пяти полей на компьютере/планшете/телефоне и переключение тем.
