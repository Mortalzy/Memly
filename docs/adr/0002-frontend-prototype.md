# ADR-0002: отдельный фронтенд-прототип

- Статус: принято для этапа дизайна.
- Дата: 6 октября 2026 года.

## Решение

По запросу пользователя до реализации E1 создаётся интерактивный макет первого выбранного дизайна.
Он расположен в `apps/web`, использует React 19, строгий TypeScript и Vite.
Это не выполнение E1/E2: сервер, пользователи, база и учебный движок не реализованы.

Для прототипа достаточно React state, hash-навигации и обычного CSS с цветовыми токенами.
React Router, TanStack Query, Tailwind, Radix и React Hook Form из ADR-0001 остаются целевым
решением для приложения; зависимостей без используемых сценариев сейчас не добавляем.
При переходе к приложению заменим навигацию и формы и подключим контракты API.
Моковые состояния и данные не должны становиться алгоритмом обучения.

## Развёртывание

Прототип собирается в статический `dist/` и публикуется в приватном Site для просмотра.
Site не меняет целевую архитектуру Express + PostgreSQL и контейнерное размещение продукта.
Исходники и lockfile коммитятся в существующий репозиторий Memly.
