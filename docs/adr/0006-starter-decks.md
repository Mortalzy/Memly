# ADR 0006: готовые наборы английского

Дата: 9 октября 2026. Статус: принято.

## Решение

Десять авторских наборов по 40 English/Russian пар хранятся в version-controlled
`apps/api/src/modules/starters/catalog.ts`. Подборка доступна каждому вошедшему
пользователю после обычного обновления и миграций. Seed, фиктивный аккаунт автора
и автоматическое заполнение личной библиотеки не требуются.

Каталог возвращает метаданные, ориентировочную сложность и ID личной копии текущего
пользователя. Предпросмотр показывает исходные 40 пар. Добавление выполняет nested
upsert Deck/Card/CardVersion: private-набор, отдельные UUID и ревизии, собственный
прогресс и обычные права владельца. Общее содержимое не становится доступным для
редактирования через CRUD наборов.

Nullable `Deck.starterKey` и уникальный индекс `(ownerId, starterKey)` ограничивают
пользователя одной существующей копией шаблона. Обычные пользовательские наборы
с NULL не ограничены этим индексом. Повторный запрос возвращает имеющуюся копию,
сохраняя пользовательские правки и прогресс. Конкурентная уникальная вставка
обрабатывается чтением победившей полной копии. Карточки создаются атомарно.

Редактирование копии не меняет источник или других пользователей. Обновление
содержимого каталога действует на новые копии. Удаление личного набора освобождает
ключ; последующее добавление создаёт свежий набор с новым ID и нулевым прогрессом.
Ключ сохраняется при переименовании, перемещении в папку и изменении видимости.

## Учебные материалы

Темы: основные глаголы, повседневные действия, люди/эмоции, еда/кафе, город/дорога,
путешествия/отель, работа/учёба, разговорные фразы, фразовые глаголы и сочетания.
Каждая карточка имеет один конкретный смысл. Многозначность ограничена тематикой;
фразовые глаголы даны с коротким контекстом. Сложность ориентировочная, без заявления
о сертифицированном соответствии CEFR. Основная разновидность — британский английский.

Все копии используют существующий движок четырёх режимов, включая обратное направление.
Письменная проверка следует общим правилам: смысловые синонимы и произвольные
альтернативные переводы не принимаются автоматически. Произношение, аудио и
автоматические обновления пользовательских копий в эту задачу не входят.
