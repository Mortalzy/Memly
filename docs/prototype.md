# Интерактивный прототип Memly

Статус: фронтенд-прототип, 6 октября 2026 года. Использован первый выбранный дизайн:
белый фон, нежные розовые поверхности, акцент #bb4e76, левое меню и карточная структура.

## Запуск

Нужны Node.js 24 и npm 11 (npm поставляется вместе с Node.js). Из корня репозитория:

```bash
npm ci
npm run dev
```

Откройте адрес Vite из терминала (обычно http://localhost:5173).
Для production-сборки: `npm run build`; для локального просмотра сборки: `npm run preview`.
Сборка находится в `dist/` корня репозитория. Её можно разместить на статическом хостинге.

## Границы

Нет API, авторизации, PostgreSQL, AI, отправки уведомлений и реального учебного движка.
Данные хранятся только в состоянии React и сбрасываются при обновлении страницы.
Числа на главной и в статистике — примеры из дизайна; в наборах показана часть карточек.
Показатель 80% в результатах теста — макет, а не оценка ответов.
Кнопки «Знаю»/«Ещё учу» только переключают карточку, не сохраняют учебный прогресс.
Форма настроек и переключатель уведомлений показывают состояния интерфейса.
Языки в редакторе демонстрируют оформление полей; пока не изменяют материал.

## Структура и проверки

Код размещён в `apps/web/src` в слоях `app`, `pages`, `entities`, `shared`.
Демонстрационные материалы отделены от компонентов. Русские тексты — в `shared/ru.ts`.
CSS содержит общие цветовые токены. Контракты и учебный движок не заполняются логикой макета.
Маршруты на hash поддерживают открытие отдельных экранов и кнопки браузера без серверного fallback.

```bash
npm run typecheck
npm run format:check
npm test
npm run build
```

Тесты поведения выполняются в DOM-окружении и проверяют переходы, карточки,
редактор, поиск и диалог папки. Они не заменяют визуальную проверку в браузере.
