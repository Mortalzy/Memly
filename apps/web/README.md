# @memly/web

Интерактивный фронтенд-прототип первого выбранного дизайна Memly.

Планируемые области: `app`, `pages`, `features`, `entities`, `shared`. Правила обучения и сетевые контракты подключаются из общих пакетов. Схема БД и серверные секреты в клиент не импортируются.

Запуск из корня: `pnpm install --frozen-lockfile`, затем `pnpm dev`.
Сборка: `pnpm build`. Проверки: `pnpm typecheck`, `pnpm format:check`, `pnpm test`.

Есть кликабельные страницы, демонстрационные материалы, редактор в памяти и адаптивное оформление.
Нет API, авторизации, базы и настоящих учебных алгоритмов. Подробности в [описании прототипа](../../docs/prototype.md).
