# @memly/web

Будущий React-клиент: страницы, пользовательские сценарии и общие компоненты.

Планируемые области: `app`, `pages`, `features`, `entities`, `shared`. Правила обучения и сетевые контракты подключаются из общих пакетов. Схема БД и серверные секреты в клиент не импортируются.

На текущем этапе здесь нет прикладного кода, зависимостей и команды запуска.
