# @memly/web

React-клиент Memly с серверной библиотекой. Запуск — в [корневом README](../../README.md).
TanStack Query хранит данные API, HTTP-клиент — в shared, действия auth — в features.
Исторический standalone прототип доступен через явный VITE_DEMO_MODE=true.

Выбранная светлая/тёмная тема сохраняется в localStorage под `memly.theme` и применяется
до рендера приложения, включая загрузку и вход. Тема относится к браузеру; при повторном
открытии Workspace выбор восстанавливается. Если хранилище недоступно, переключение
продолжает работать и интерфейс сообщает, что сохранение не удалось.

В редакторе «Добавить списком» открывает массовый ввод с предпросмотром. Одна непустая
строка — одна карточка; слово и перевод разделяются первым пробелом (включая несколько
пробелов), табуляцией или `;`. Остаток строки становится переводом. Для словосочетаний
выберите табуляцию или `;`. Пустые строки пропускаются, текст не переводится и не исправляется.

Строки без пары или с превышением длины полей блокируют весь импорт. Общий лимит —
500 карточек с учётом существующих строк. При добавлении сохраняются заполненные и
частично заполненные карточки, полностью пустые заготовки удаляются. Импорт меняет
только черновик: для записи в PostgreSQL нажмите «Сохранить набор». Отмена сохраняет
черновик без изменений. Это вставка текста, а не загрузка CSV-файла с кавычками.

Все четыре режима в подключённом приложении используют `features/study-client` и серверные
сессии. StudySetup/StudyQuestionInput/StudyResults отделены от управления состоянием
страницы. Черновик теста сохраняется после 800 мс без ввода; интерфейс показывает статус
сохранения и повтор действия после сетевой ошибки с тем же ID. Обновление страницы
восстанавливает последнее активное занятие. История открывает конкретное занятие через
`#/study/:deckId/:mode?session=:sessionId`. Standalone PrototypeStudy используется только
в явном demo-режиме. Серверные ответы теста не включаются в production-клиент.

SpeechButton использует общий контроллер `shared/speech` и Web Speech API: играет только
один текст, повторное нажатие останавливает звук. Кнопка на карточке читает видимую сторону;
кнопки вопроса и игрового поля не отправляют учебные действия. В тесте доступна только
озвучка вопроса, ответы появляются в разборе после сдачи. При перевороте, смене карточки,
уходе со страницы или скрытии вкладки звук останавливается.

Для текущих English/Russian наборов язык определяется по преобладающему алфавиту:
en-US / ru-RU. Это не распознавание произвольного языка. Используется голос того же языка,
предпочтительно с точным региональным тегом. Если подходящего голоса нет в списке,
выбор делегируется браузеру с явно указанным `lang`. Если выбранный голос недоступен,
контроллер один раз повторяет запуск с автоматическим выбором и тем же языком.
Следующий клик повторно считывает загруженные голоса; отсутствие голоса определяется
ошибкой синтеза, а не только содержимым списка.
Качество, наличие голосов и потребность в интернете зависят от устройства и браузера.
Отсутствие API/голоса и ошибки воспроизведения выводятся рядом с кнопкой, не блокируя обучение.
API-ключи, серверный TTS, автозапуск озвучки и записи пользователя не добавлены.

В подключённой библиотеке вкладка «Наборы Memly» использует StarterCatalog:
10 наборов по 40 English/Russian карточек, поиск, фильтр сложности, полный предпросмотр
и добавление через API. После добавления можно открыть свою копию, редактировать её и
изучать во всех режимах. Моя библиотека обновляется после добавления. Демонстрационные
наборы standalone-прототипа не используются как источник этой подборки.
