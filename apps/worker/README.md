# @memly/worker

Будущий процесс фоновых задач: обработка документов и медиа, AI-генерация, рассылки и очистка временных файлов. Появится при внедрении Redis + BullMQ.

Использует те же серверные сценарии и схемы данных; не создаёт второй набор правил авторизации или обучения.

На текущем этапе здесь нет прикладного кода, зависимостей и команды запуска.
