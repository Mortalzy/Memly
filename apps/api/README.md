# @memly/api

Будущий Express API: HTTP-интерфейс и модули авторизации, пользователей, наборов, библиотеки, обучения, игр, групп и административных функций.

Модуль содержит транспортный слой, сценарии и запросы к данным по необходимости. Сервер отвечает за права доступа, проверки ответов и запись прогресса. Публичные DTO определяются в `packages/contracts`.

На текущем этапе здесь нет прикладного кода, зависимостей и команды запуска.
